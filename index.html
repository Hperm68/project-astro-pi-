ISS Speed Estimate

This project estimates the speed of the International Space Station by recording two ISS subpoint locations 60 seconds apart, computing the distance along Earth’s surface with the Haversine formula, and dividing by time.

Method
2 points / 60 seconds
Formula
Haversine (great-circle)
Output
result.txt (one line)

How it works

  1. Speak: “plz move camera to windows in 15 sec”
  2. Wait 20 seconds
  3. Record Point A (lat/lon) + take Photo A
  4. Wait 60 seconds
  5. Speak again + wait 20 seconds
  6. Record Point B (lat/lon) + take Photo B
  7. Compute distance (Haversine) and speed = distance ÷ time
  8. Write final speed to result.txt (one line)

Why Haversine?

Earth is curved, so the shortest path between two latitude/longitude points is a “great-circle” distance. The Haversine formula computes this distance accurately on a sphere. 

speed = distance / time
distance = R * c  (great-circle)

Judge-ready explanation (copy/paste)

This program estimates the speed of the International Space Station by recording two positions 60 seconds apart. Before each measurement, an audio message is played and the program waits to allow time for camera positioning. The distance between the two positions is calculated using the Haversine formula, which accounts for the Earth’s curvature. The final speed is calculated by dividing the distance by the time difference and written to a single-line output file as required.
